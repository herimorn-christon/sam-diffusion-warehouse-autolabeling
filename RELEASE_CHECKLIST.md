# Release checklist — author must complete before Zenodo deposit or journal submission

- [ ] Confirm research data ownership and rights to re-share every source image.
- [ ] Verify restrictions of third-party image sources, datasets and pretrained model licenses.
- [ ] Review privacy, consent and sensitive metadata in image paths, reviewer records and checkpoint manifests.
- [ ] Confirm whether peer-review is double-anonymous; scrub author-identifying file metadata if needed.
- [ ] Inspect curated JSON/CSV for potentially sensitive free text before any public release.
- [ ] State accurately that no full reproduction (weights, source images, code) is currently possible from this package.
- [ ] Approve which files are public, restricted or not releasable.
- [ ] Choose the appropriate license based on rights rather than assuming everything is CC BY.
- [ ] Deposit and verify the exact public archive on a suitable research repository.
- [ ] Add the **real** DOI and final title/metadata in the manuscript Data Availability statement.
- [ ] Compare published repository content with SHA256SUMS.txt after upload.

**No release was performed during document preparation.**
